# 官方 V8 静态集成

## 1. 来源与版本

使用官方原始 V8 **13.6.233.17**，固定提交 `b0a55a7dad7f536cce1f9aaddba89894c8533946`，锁文件为包内 `ZenTS~/v8/official-source-lock.json`。不使用 Puerts 的 SDK 发布物、绑定层或运行时，也不嵌入 Node.js。上游源码不施加 ZenTS 补丁，适配器在独立目录编译。

V8 编译为静态库，ZenTS 适配器链接该库；不将整棵 V8 源码嵌入 libil2cpp，也不在每次 Unity 编译时完整重编 V8。

## 2. 平台产物

| 平台 | 集成 |
|---|---|
| Windows Editor / Win64 | DLL 内静态 V8 / Player 静态库 |
| macOS Editor / Player | dylib 内静态 V8 / 对应 arm64/x64 静态库 |
| Android | Linux/NDK 构建对应 ABI 静态库 |
| iOS / 模拟器 | 分别构建 JITless 静态库，导出到 Xcode |
| WebGL / 微信 | 不链接 V8，使用 HostJs |

原生不支持 V8 的目标不回退其他引擎。不同 OS/CPU、设备/模拟器、编译器与 GN 选项的库不能混用。

## 3. 构建和 SDK 安装

Windows 先 `build_official.py` 构建原始 SDK，再 `build_win64.py` 编译 ZenTS 静态适配库与 Editor 插件；Apple/Android 用 `build_platform.py`。构建在包外输出，完整 SDK 用 `import_platform.py` 或 Editor 导入菜单安装到项目 Library。准确命令见[安装指南](../../guides/install.md)。

SDK 身份包括来源 revision、目标 OS/CPU、工具链、GN、JITless、ICU/snapshot 配置、引擎及适配器源码身份和文件 SHA-256。静态编译选项与头文件宏必须一致；不能通过改 manifest 使失配二进制通过检查。适配层更新可复用匹配的原始 V8 静态库。

Editor 插件和稳定 GUID meta 自动生成到 Assets，不写 package。已加载插件不原地覆盖；重启后激活新 SDK。原生二进制不纳入源码 Git，团队可分发经过校验的完整 SDK。

## 4. 执行边界

`engine/v8/V8Engine.cpp` 实现 EngineApi；Editor ABI 位于 `V8Mono.cpp`，托管 P/Invoke 位于 `Runtime/Mono/Engine/V8`。CLR 绑定内核不包含 V8 SDK 值，不依赖 v8::Local 或引擎对象裸地址。

值所有权、主线程、异常、持久函数与 Reset 规则见[引擎边界](07-ENGINE-BOUNDARY.md)。Inspector 只编入 Editor 接口，不给 Player 增加监听。

## 5. 实际验收

Windows Editor/Win64 和 macOS arm64 Editor 有最新 435 命名用例记录。macOS Player、Android 模拟器、iOS x64 模拟器已有运行验证；iOS arm64 仅无签名编译。macOS x64 Editor 插件编译通过未运行。具体工具链与限制以[对齐状态](../03-ALIGNMENT.md)为准，不把脚本参数存在当作真机支持证明。
