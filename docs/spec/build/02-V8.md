# 构建 — Native V8

本文规定目标集成方式。P1 只有引擎边界及构建配方，**没有已构建或验收的 V8 运行时**。

## 1. 目标矩阵

| 目标 | 架构起点 | 运行方式 |
|---|---|---|
| Windows Editor / Win64 Player | x64 | V8 |
| macOS Editor / Player | arm64、x64 | V8；分别验收产物及签名配置 |
| Android Player | 优先 arm64 | V8；其他 ABI 按需补齐并独立验收 |
| iOS Player | arm64 设备 | JITless V8，不要求可执行内存/JIT 权限 |

WebGL/小游戏使用平台 VM，不链接另一个 V8。没有可用 Native V8 的其他 Native 目标不回退 QuickJS。iOS simulator/XCFramework 打包、macOS 签名及其他 ABI 不能仅凭脚本参数宣称完成。

## 2. 版本与工具链

固定一个完整 V8 revision；headers、编译宏、静态库和运行库须同一配方匹配。至少记录 source SHA、dirty/patch 状态、GN 参数、host/toolchain、OS/CPU、JITless、pointer compression/sandbox、ICU/Intl、snapshot/startup data 和产物哈希。

不能把最新版 headers 与旧静态库混用，也不能把 V8 C++ ABI 暴露给 Mono。Unity/libil2cpp 适配层和 V8 封装分别维护依赖边界。V8/编译器升级后重新验证 ABI、构建及行为。

## 3. P1 构建配方

包内 `ZenTS~/v8/build.py` 只操作已有、依赖已同步且 revision 匹配的干净 checkout，不下载源码或切换分支。

```text
python build.py --source <v8-checkout> --revision <完整40位SHA> --target windows --cpu x64 --out <output> --dry-run
```

去掉 dry-run 才执行 GN/autoninja 并构建 v8_monolith；成功后写 zents-v8-build.json。iOS 配方强制 JITless，并关闭该配方不采用的 pointer compression/sandbox；是否适用于最终 revision 须在 P2 实编确认。当前配方关闭 ICU 并内嵌启动数据，改变 Intl/启动策略要更新 manifest。

P1 只验证五组 dry-run、拒绝非固定 revision 和流式产物哈希；没有为尚未实测的 revision 作发行承诺。

## 4. Editor 集成

Mono 通过 ZenTS 自有 managed EngineApi 及原生稳定边界连接 V8。跨边界传指针/长度、明确布局的 POD、状态或输出参数；不传 v8::Local/v8::Global/C++ STL。

JS→C# 入口捕获托管异常并返回错误结果；native callback 返回安全点再设置 JS 错误。C#→JS 由 V8 TryCatch 等机制捕获失败后转换 JsScriptException。调试传输、日志和回调不能绕过 [Mono 边界](./03-MONO-CALLBACK-GATE.md)。

## 5. Il2Cpp 集成

CLR 绑定计划与 Marshal 在 C++；通过自有引擎接口访问 V8。通用 invoker 与预编译签名桥并存，优化必须实测。Win64、ARM64 的参数/struct 返回/函数指针 ABI 各自验证，不能把现有 Win64 trampoline 当作全平台实现。

## 6. Handle、GC 与域生命周期

短期值受 handle scope 管理，长期函数/模块/wrapper 用持久 handle；弱回调排队释放 CLR 根。不能保存会被移动 GC 失效的裸 JS 对象地址。identity cache 使用稳定 token，且仅在相应对象被保活期间有效。

默认在 Unity 主线程执行互操作；V8 内部后台线程不授予业务跨线程访问 CLR/Unity API 的权限。Reset 释放旧域 handle、缓存与托管引用并失效 generation；不在活跃 callback 中立即销毁 context/isolate。

## 7. 必须验收

Editor Domain Reload、重复 Play、异常与嵌套重入、ESM、微任务、typeof/门面、委托身份、ref/out/Opaque、含引用 struct、增量 GC、Reset 和签名桥缺失均有测试。原生库能链接和 JS 能 Eval 只是前置检查。

调试与模块分别见 [调试器](./04-JS-DEBUGGER.md)、[原生模块](./05-NATIVE-MODULES.md)；版本安装见 [11-MULTI-VERSION.md](../11-MULTI-VERSION.md)。
