# API reference

The public surface comprises host entry points, script utilities, and configuration attributes. Hooks and native ABIs are implementation details.

| Task | Reference |
|---|---|
| Initialize, Reset, bind exports | [JsAppDomain](js-app-domain.md) |
| Types, arrays, generics, Opaque, delegates | [JavaScript API](js-surface.md) |
| Aliases, policies, extensions | [Attributes](attributes.md) |
| SDK, TS, debugger, AOT XML settings | [Settings](../spec/15-SETTINGS.md) |
| Exact conversion and lookup rules | [Specification](../spec/00-OVERVIEW.md) |

Examples assume an initialized domain and available CLR metadata/AOT code. API references do not replace target builds and runtime validation.
